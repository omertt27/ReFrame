How it works

Click a component. Edit it. Done.

ReFrame runs alongside your existing dev server — nothing about your project is modified to make it work.

01

Point it at your app

Run ReFrame's dev tool next to your already-running next dev. No config file, no injected script in your source.

02

Click to resolve

Click anything in the live preview — ReFrame walks the React tree back to the exact component, prop, or class in your source.

03

Edit visually

Adjust spacing, size, and layout from a real property panel. Choose "this instance" or "the shared component."

04

Get a clean diff

Edits land as targeted AST mutations — shared components, prop overrides, and conditionals stay intact.

Why not AI-assisted editing?

Because "move this 12px" doesn't need a prompt.

AI is great at generating a first draft and bad at the mechanical follow-up. ReFrame is the manual editing layer that was missing.

Component-aware, not DOM-aware

Diffs a developer would actually approve

Most direct-manipulation editors rewrite the rendered className string. ReFrame edits the AST node that produced it — so a prop-driven conditional stays a conditional.

Navbar.tsx
function Navbar({ variant }: { variant: "transparent" | "solid" }) {
return (
- <nav className={variant === "transparent" ? "h-16 ..." : "h-20 ..."}>
+ <nav className={variant === "transparent" ? "h-16 ..." : "h-24 ..."}>
);
}
Features

Built around your source, not around a canvas

✓

Real source code

Edits are AST mutations written back with recast — not full-file regeneration.

✓

Shared components

Edit a shared definition once, or scope the change to a single instance — you choose.

✓

Tailwind-aware

Snaps to the spacing scale when it fits, falls back to an arbitrary value when it doesn't.

✓

Prop-aware conditionals

Ternary and clsx()/cn() class expressions are edited in place, never flattened.

✓

Minimal git diffs

Only the mutated subtree is reprinted — the rest of the file stays byte-identical.

✓

Zero AI dependency

No chat, no tokens, no model calls anywhere in the editing path.
